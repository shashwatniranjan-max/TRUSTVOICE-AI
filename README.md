## Important

This is an internal prototype. The risk engine uses transparent keyword/pattern rules and scripted scenarios. It does not claim a trained anti-spoofing model or unrestricted access to ordinary cellular call audio.

SIH-final work can replace these components with trained models and a supported VoIP/telephony audio-access path.
